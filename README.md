
# 三角洲行动辅助工具 · Delta Force Assistant

> 一站式整合 **三角洲行动辅助卡盟**、**科技卡网**、**透视网站**、**自动瞄准** 与 **雷达物资** 的完整方案。本仓库持续收集 **三角洲行动辅助源码**、**免费辅助工具** 及 **最新内部辅助网** 入口，适用于手游及 PC 端。

---

## 📌 功能特点（Feature List）

- **透视（ESP）**：支持玩家、物资、载具的实时透视显示，可切换线框/骨骼模式。
- **自瞄（Aimbot）**：可调节平滑度和锁定区域，适配不同灵敏度。
- **雷达（Radar）**：小地图外置窗口，显示全图敌人与物资点。
- **物资透视（Loot ESP）**：高亮显示高级武器、护甲、医疗品，支持自定义过滤。
- **一图流集成**：整合所有辅助功能于单一界面，一键启动。
- **免费/卡盟双模式**：提供免费基础版，高级功能可通过 **三角洲行动辅助卡盟** 获取授权码。
- **源码开放**：部分模块开源，可自行编译定制（见 `/src` 目录）。

## 🔧 安装与使用（Installation & Usage）

1. 克隆本仓库：
   ```bash
   git clone https://github.com/Go1337/deltaforce-sanjiaozhou-fuzhu.git
   ```
2. 运行依赖安装脚本（支持 Windows / Android 模拟器）：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动主程序 `main.py`，按提示选择游戏版本（PC / 手游）。
4. **卡网用户**：在登录界面输入从 **三角洲行动辅助科技卡网** 获取的 Token。
5. 免费用户可直接试用基础透视功能（限时 30 分钟）。

> 📌 如需获取最新内部版本或卡盟充值，请访问我们的 **三角洲行动辅助官网**（见下方 Issue #1）。

## 📋 常见问题（FAQ）

### Q1：哪里可以找到可靠的 **三角洲行动辅助卡盟**？
A：推荐使用我们合作的卡盟平台，支持支付宝/USDT 支付，提供 24 小时自动发卡。具体入口请查看 **Issue #2** 和 **Issue #5**。

### Q2：是否支持 **三角洲行动手游**？
A：完全支持。我们专门优化了触控映射和渲染层注入，适配 Android 9+ 和 iOS（越狱）。

### Q3：如何避免封号？
A：本工具采用内核级驱动隐藏和随机偏移量，同时建议使用 **内部辅助网** 提供的定制版本（见 Issue #3）。我们不保证 100% 安全，但已稳定运行 3 个月以上。

### Q4：有 **免费辅助** 吗？
A：有。我们提供免费版（透视+雷达），但功能有限。如需完整自瞄和物资透视，请考虑购买 **卡盟** 授权。

### Q5：源代码在哪里？
A：部分源码已开源，位于 `/src`。完整源码仅对内部会员开放，可通过 **三角洲行动辅助论坛**（Issue #6）获取。

### Q6：什么是 **一图流**？
A：一图流是指将所有辅助信息（敌人位置、物资、撤离点）实时绘制在同一张动态地图上，无需切换窗口，可直接作为游戏覆盖层。
